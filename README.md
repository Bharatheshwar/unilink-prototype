## 📌 Problem Statement

Student innovation in universities often stays trapped within local campus boundaries. Cross-disciplinary builders struggle to recruit teammates from neighboring institutions, academic research is isolated within department walls, and verified peer recognition is fragmented. UniLink bridges the digital and physical campus divide by creating a frictionless discovery and collaboration layer for student innovators across institutions.

---

## ⚡ Core Features

* **🎙️ Live Hackathon Stream Hub:** Interactive multi-campus stream featuring dynamic audio visualizers, live squad matcher, and real-time chat coordination.
* **🗺️ Campus Event Geofence Map:** Interactive campus directory displaying real-time space occupancy and instant 1-click RSVP functionality.
* **🪪 Verified Student ID & Laser NFC Scanner:** Simulated digital student credential scanner featuring laser sweep animations and credential verification states.
* **🔬 Peer-Reviewed Project Network:** Real-time project showcase allowing verified cross-campus reviews, feedback, and community endorsements.
* **💬 Inter-Campus Discussion Forums:** Centralized topic-based feeds for hackathon team formation, robotics, and academic discussions.
* **📱 Responsive Cross-Platform Architecture:** Fully optimized layout for desktop monitors, tablets, and mobile devices.
